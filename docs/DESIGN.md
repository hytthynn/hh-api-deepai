# Дизайн-система hh-api

Тёмная минималистичная тема, чёрный фон + лаймовый акцент. Без теней, градиентов, скруглений больше 10 px и декоративных иллюстраций. Плотность — как у терминала: много воздуха по краям, плотные строки внутри таблиц.

## Токены

```css
:root {
  --bg:            #0A0A0A;
  --bg-elevated:   #111111;
  --bg-hover:      #171717;
  --bg-active:     #1C1C1C;
  --border:        #1F1F1F;
  --border-strong: #2A2A2A;

  --fg:            #EDEDED;
  --fg-muted:      #8A8A8A;
  --fg-faint:      #5C5C5C;

  --lime:          #C6FF3D;
  --lime-hover:    #D4FF6B;
  --lime-dim:      #9BE02A;
  --lime-ghost:    rgba(198, 255, 61, 0.08);
  --lime-border:   rgba(198, 255, 61, 0.28);

  --danger:        #FF4D4D;
  --danger-ghost:  rgba(255, 77, 77, 0.10);
  --warn:          #FFB020;
  --warn-ghost:    rgba(255, 176, 32, 0.10);
  --info:          #7AA2FF;

  --radius-sm: 6px;
  --radius:    10px;
  --radius-lg: 14px;

  --font-sans: "Geist", "Inter", system-ui, sans-serif;
  --font-mono: "Geist Mono", "JetBrains Mono", ui-monospace, monospace;

  --space-1: 4px;  --space-2: 8px;  --space-3: 12px;
  --space-4: 16px; --space-5: 24px; --space-6: 32px; --space-7: 48px;

  --sidebar-w: 240px;
  --content-max: 1280px;
}
```

Семантика цветов: лайм — только действия и положительные метрики; красный — ошибки; янтарный — предупреждения и кулдаун; серый — неактивное. Лайм никогда не используется для больших заливок (только кнопки, бейджи, линии графиков, фокус).

## Типографика

| Роль | Размер / интерлиньяж | Шрифт |
|---|---|---|
| H1 страницы | 24 / 32, 600 | sans |
| H2 секции | 16 / 24, 600 | sans |
| Body | 14 / 20, 400 | sans |
| Small / метки | 12 / 16, 500 | sans |
| Числа, ключи, id | 13 / 18, 400 | mono |
| Заголовки таблиц | 11 / 16, 600, uppercase, +0.04em | sans |

Правило: любые числовые значения (баланс, токены, латентность, timestamps, ключи, id) — моноширинный шрифт и `font-variant-numeric: tabular-nums`.

## Каркас

```
┌────────────┬──────────────────────────────────────────────┐
│ hh-api     │  Заголовок страницы            [действия]    │
│            ├──────────────────────────────────────────────┤
│ Обзор      │                                              │
│ Аккаунты   │   контент, max-width 1280, паддинг 24        │
│ Ключи      │                                              │
│ Модели     │                                              │
│ Логи       │                                              │
│ Настройки  │                                              │
│            │                                              │
│ ● шлюз ok  │                                              │
└────────────┴──────────────────────────────────────────────┘
```

Сайдбар: фон `--bg-elevated`, правая граница `--border`. Активный пункт: фон `--lime-ghost`, левая полоса 2 px `--lime`, текст `--fg`. Высота пункта 36 px, паддинг 10/12.

Индикатор шлюза: точка 6 px `--lime` (или `--danger`), текст 12 px `--fg-muted`, обновление раз в 15 с по `/healthz`.

## Компоненты

**Кнопка.** Высота 32 px (`sm`) / 36 px (`md`). Primary: фон `--lime`, текст `#0A0A0A`, вес 600, hover `--lime-hover`. Secondary: прозрачный фон, граница `--border-strong`, текст `--fg`, hover `--bg-hover`. Ghost: без границы, текст `--fg-muted`, hover текст `--fg`. Danger: текст `--danger`, граница `--danger` 1 px, hover `--danger-ghost`. Радиус `--radius-sm`. Фокус: `outline: 2px solid var(--lime); outline-offset: 2px`. Disabled: opacity 0.4, `cursor: not-allowed`.

**Поле ввода.** Высота 36 px, фон `--bg`, граница `--border`, радиус `--radius-sm`, паддинг 0 12. Фокус: граница `--lime-border`, кольцо `0 0 0 3px var(--lime-ghost)`. Ошибка: граница `--danger`, текст ошибки 12 px `--danger` под полем. Моноширинные поля (ключи, прокси) — `--font-mono`.

**Бейдж статуса.** Высота 20 px, паддинг 0 8, радиус 999, 11 px / 600 uppercase.

| Статус | Текст | Фон | Цвет |
|---|---|---|---|
| active | active | lime-ghost | lime |
| cooldown | cooldown | warn-ghost | warn |
| exhausted | exhausted | `#1A1A1A` | fg-muted |
| dead | dead | danger-ghost | danger |
| pending | pending | `#1A1A1A` | fg-muted |
| disabled | off | `#141414` | fg-faint |

**Карточка.** Фон `--bg-elevated`, граница `--border`, радиус `--radius`, паддинг 20. Заголовок 12 px uppercase `--fg-muted`, значение 28 px/600 mono, подпись 12 px `--fg-faint`.

**Таблица.** Заголовок: фон `--bg`, граница снизу `--border`, 11 px uppercase `--fg-muted`, высота 36. Строка: высота 44, граница снизу `--border`, hover `--bg-hover`. Числовые колонки — вправо, mono. Первая колонка — 12 px паддинг.

**Модалка.** Оверлей `rgba(0,0,0,0.72)`, панель 480 px, фон `--bg-elevated`, граница `--border`, радиус `--radius-lg`, паддинг 24. Заголовок 16/600, футер — действия справа.

**Тосты.** Правый низ, ширина 320, фон `--bg-elevated`, левая полоса 2 px (lime/danger/warn), автоскрытие 4 с.

**График.** Линия 1.5 px `--lime`, заливка `--lime-ghost` до нуля. Сетка: 3 горизонтальные линии `--border` без подписей, ось Y — подписи 10 px `--fg-faint`. Точки не рисуются. Hover — вертикальная линия `--border-strong` и тултип.

**Прогресс-бар.** Высота 4 px, фон `--border`, заполнение `--lime`, радиус 999. Проценты — mono 12 px справа.

## Правила

- Никаких теней. Глубина — только фоном и границей.
- Один акцентный элемент на экран (primary-кнопка или активный пункт меню).
- Иконки 16 px, stroke 1.5, цвет наследуется от текста.
- Все состояния (loading/empty/error) обязательны на каждом экране.
- Анимации: 120 мс `ease-out`, только opacity/transform. Никаких layout-анимаций.
- Мобильная вёрстка не поддерживается (локальный десктоп), минимальная ширина 1024 px.
